## Defects found and fixed while implementing (preserved, not hidden)
1. **Stream flag changed a request's identity (found by the stream/non-stream equivalence test, commit 3).** The request key was computed over the whole parsed request including `stream`, so a request and its streamed twin got different ids and content. The plan requires them to agree. Fixed in the same commit by excluding `stream` from the identity; the equivalence test, and a mutation that puts it back (T1), now guard it.
2. **golangci-lint (errcheck) findings in commit 1** (an unchecked `<-errc` and unchecked `fmt.Fprintf` results). Fixed before committing.
3. **Test gaps found by my own mutation runs.** (a) Ignoring stream write errors survived because the fake writer did not count failed write attempts; the test now asserts three attempts. (b) Removing the per-event flush survived because my gating wrapper flushed the response itself, so the test could not fail for the reason it claimed; the wrapper now passes through only what the mock flushes. (c) An equivalent mutant (`<=` instead of `<` for error rate 0) cannot be killed: a score of exactly 0 has probability 2^-53.
4. **Harness errors, not product defects.** My first mutation script generated Python with broken quoting, so five "surviving" mutations had never been applied (visible as `SyntaxError` in the raw output); I replaced it with a driver that asserts each edit applied (output below shows 19 of 19 detected). My first A7 grep had a quoting error and exited 2 (visible in the raw acceptance output below); the corrected grep follows it.
