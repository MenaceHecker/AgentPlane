Manager tests (5): loopback health, readiness and metrics, clean cancellation returning nil with ports closed, busy port failing the start, bad and conflicting addresses refused, nothing reconciled (Tenant unchanged after 3 s), no non-API-server Lease, no owned objects, scheme recognizes both kinds. Normal runs create no leftover.
3. **A too-broad lease assertion** in my manager test (the API server writes its own identity Leases) failed on both versions; narrowed to "no Lease other than API-server identity Leases".
4. One test-construction bug (nesting under an absent `rollout`) fixed in the Agent rollout test.
