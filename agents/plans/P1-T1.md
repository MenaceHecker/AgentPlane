## Goal
Introduce a reproducible Kubebuilder project around the existing agentplane.io/v1alpha1 contracts, generated installable Tenant/Agent CRDs, and a minimal controller-runtime manager entry point. Preserve existing JSON/zero/absence semantics and all Phase 0 mock/contract/cleanup checks. Prove schema admission against disposable API servers without creating or contacting a live cluster. ## API and schema decisions
- Preserve all existing type names, JSON tags, group/version, scopes, field paths and fixture serialization; no defaulting or nil-to-zero normalization of optional fields. Keep Agent.spec.replicas optional pointer with absent distinct from explicit 0. Status subresources enabled; Conditions remain list-map keyed by type. Typed round-trip/deep-copy tests remain intact.
- Tenant CRD: plural tenants, singular tenant, kind Tenant, scope Cluster, served/storage v1alpha1, status subresource. Require spec and its displayName/quota/budget/egress objects; displayName nonempty. Quota CPU/memory/pods present; pods integer >=0. Both budget fields present, integer >=0 with existing int64/int32 ranges. Zero budgets are valid, not unlimited. Egress allowedTools may be absent/empty: both mean deny-all in later gateway behavior.
- Agent CRD: plural agents, singular agent, scope Namespaced, same served/storage version and status subresource. Require spec.image/model/budget/resources; image/model nonempty. Replicas optional integer >=0, no CRD default. Budget same required/zero/nonnegative semantics. Tools absent/empty allowed. Sandbox class, if set, must be hardened; no Kata feature added. Rollout remains optional typed data for later delivery work, not a functioning canary implementation.
- Use generated Kubernetes resource.Quantity and ResourceRequirements schema shapes; do not invent lossy regexes, convert quantities to floats, or claim all quantity semantics/resource policy are enforced. Semantic negative compute quantities and required requests/limits policy need the later validation/controller/policy plans; test coverage and docs must explicitly identify that boundary. Similarly no tenant-aggregate/agent-versus-tenant budget lookup, registry allowlist, latest-tag policy or cross-resource check here.
- Printer columns: Tenant DisplayName and Ready; Agent Replicas and Ready; both Age. Ready reads the Ready condition if present; absent stays blank/unknown, not synthetic success. No status default or fabricated observedGeneration. Do not create short names or new identity conventions without plan revision.
- Generate structural apiextensions.k8s.io/v1 CRDs with preserve-unknown-fields disabled. Unknown-field pruning is Kubernetes behavior, not an automatic reject guarantee. Do not report an omitted required field as tested by a typed Go value that serializes a zero in its place: negative admission fixtures must use raw unstructured JSON/maps.
