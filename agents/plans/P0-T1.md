## Security-sensitive
Yes: `.gitignore`, `.pre-commit-config.yaml`, `.github/workflows/ci.yml`, Makefile secret-scan and kind lifecycle recipes, and any shared check script. Review ignored paths, tracked secret exposure, redacted output, full-history scanning, action/tool pins, minimal workflow permissions, untrusted PR handling, and error propagation. No Azure credentials, write-capable workflow tokens, `pull_request_target`, real LLM calls, or arbitrary cluster/context deletion. No application auth, budget, audit-chain, policy, or IAM implementation is in scope.
